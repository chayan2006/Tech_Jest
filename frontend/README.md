# Frontend

The frontend is the Next.js presentation layer:

- `src/app/` contains pages, layouts, route handlers, and styles required by Next.js.
- `frontend/components/` contains reusable client-facing components such as navigation, the profile badge, and the logo interaction.

The app router stays under `src/app/` because Next.js requires that convention for this project. Run it from the repository root with `npm run dev`.
